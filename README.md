# ALEJA ESTUDIO

Editor creativo independiente de Aleja.

## Publicación en GitHub Pages

1. Abre **Settings → Pages** en este repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/(root)`.
4. Guarda los cambios. La dirección prevista será:

   https://anhjs01.github.io/lienzo-aleja/

El editor estático no necesita un servidor para abrirse. Las tipografías adicionales se cargan desde Google Fonts cuando se muestran o seleccionan en el catálogo.

## Regreso al calendario

El enlace de marca apunta provisionalmente a la publicación de GitHub Pages del proyecto principal. Si el calendario usa otro dominio público, actualiza ese destino en `index.html`.

## Datos y proyectos

Los proyectos y el guardado local permanecen en el navegador y en el origen de este sitio. Exporta los proyectos importantes a JSON antes de limpiar los datos del sitio anterior. GitHub Pages aloja los archivos de la aplicación; no es una base de datos ni un servicio de almacenamiento de proyectos de usuarios.
